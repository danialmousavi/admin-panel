A **feature-rich admin panel** project for managing a store and users.

---

## 🛠 Technologies & Libraries

This project is built using:

- **React 19** and **React DOM 19**
- **Redux Toolkit** and **React Redux**
- **React Router DOM v7**
- **Formik** and **Yup** for form management and validation
- **Axios** for HTTP requests
- **CKEditor 5 React** for rich text editing
- **Chart.js** for charts and data visualization
- **React Select Search** for searchable select fields
- **SweetAlert2** for beautiful alerts
- **Jalali Moment** for Persian calendar support
- **Prop-Types** for prop validation

---

## 🎯 Features

The panel includes the following sections:

### Dashboard
- View overall statistics and charts

### Store
- Manage product groups
- Manage products
- Manage colors, warranties, and brands
- Manage discounts

### Orders & Cart
- Manage carts
- Manage orders
- Manage shipping methods

### Users & Staff
- View users
- Manage roles and permissions

### Communications
- Manage questions and comments
